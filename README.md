# Dev Jangra — Technical Support Engineer Portfolio

Responsive single-page portfolio. No framework or build process required.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with your real email.
2. Replace the LinkedIn and GitHub URLs with your profiles.
3. Replace the phone number if you want it displayed.
4. Add your real resume as `assets/Dev_Resume.pdf`.
5. For the hero photo, replace the placeholder `.avatar-placeholder` in `index.html` with your image, or add an `<img>` and style it like the placeholder.

## GitHub Pages
Create a repository named `YOUR_USERNAME.github.io`, upload all files, then enable:
Settings → Pages → Deploy from branch → main → root.

## Vercel
Import the GitHub repository into Vercel. Framework: Other. No build command is needed. Deploy.
